# ✨ Diwali Muse - An Enchanting Diwali Experience For Her ✨

A unique, interactive, and deeply romantic Diwali web experience created for pairing festive celebration with personal affection. Inspired by modern interactive Diwali wishes, elevated with handcrafted tactile animations, Web Audio sound design, and an intimate love letter.

---

## 🌟 The Interactive Journey

1. **The Spark in the Dark (Ignite the Diya)**:
   - An unlit brass Diya sits in a celestial midnight cosmos with lazy glowing embers.
   - Touching the wick ignites an organic, multi-layered dancing flame with ambient light spreading across the marble floor.

2. **The Sacred Rangoli Bloom**:
   - An intricate 8-fold sacred geometric Rangoli traces outward in concentric rings of gold, saffron, and ruby.
   - Tapping or swiping the Rangoli scatters realistic falling marigold and rose flower petals accompanied by temple chime arpeggios.

3. **Sky Lantern of Wishes**:
   - A glowing paper lantern inscribed with your personal wish for the two of you rises smoothly into the star-filled heavens.

4. **Celebration & Royal Gift Card**:
   - **Fireworks Sky**: Tap anywhere in the sky to launch fireworks, including romantic heart-burst peonies and golden willows!
   - **Interactive Phuljhadi (Sparkler)**: Toggle the sparkler to turn the cursor/finger into a burning handheld sparkler emitting crackling electric sparks.
   - **Royal Envelope**: Tap the crimson wax seal to pop golden confetti and reveal the parchment letter.
   - **5 Diyas of Love**: 5 glowing interactive lamps she can tap to reveal secret romantic reasons she lights up your life.
   - **Photo Frame**: Displays your favorite memory together.
   - **Synthesized Ambient Music**: Built-in Web Audio API engine providing relaxing Indian classical tanpura drone & sitar harmonics without any external audio file dependencies.

## 🚀 Getting Started

### Run Locally

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev
```

Open `http://localhost:5173/` in your browser.

### Personalizing For Her

1. Click the **"Customize & Share Link"** button on the celebration card.
2. Enter:
   - **Her Name / Nickname** (e.g. *Meri Jaan*, *Simran*, etc.)
   - **Your Name** (e.g. *Himadri*)
   - **Love Note**: Write your own touching letter.
   - **Lantern Wish**: The message inscribed on the rising sky lantern.
   - **5 Diyas**: Customize the 5 secret reasons she lights up your world.
   - **Photo URL** (optional): Paste a link to a favorite photo of you two.
3. Click **"Copy"** or **"Share on WhatsApp"** to generate a pre-configured personalized link!

## 🛠️ Tech Stack

- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **HTML5 60fps Canvas** (Starry cosmos, particle fireworks, rangoli rendering, and sparkler physics)
- **Web Audio API** (Pure mathematical audio synthesis: singing bowls, firework thuds, sparkler sizzle, ambient tanpura drone)
- **Canvas Confetti & Lucide React**
